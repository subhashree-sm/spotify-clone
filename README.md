# 🎵 Spotify Clone Homepage

A clean, responsive replica of the Spotify web player homepage built with HTML5 and CSS3. 

---

### 🎨 Overview

This project focuses on translating Spotify's iconic dark-themed interface into a structured web page. It highlights core layout techniques, custom styling, and component structuring designed in Figma and brought to life through code.

---

### 🛠️ Built With

* **HTML5:** Semantic layout structure (sidebar, main content grid, player bar)
* **CSS3:** Custom flexbox & CSS grid, hover states, and smooth scrolling
* **Figma:** Initial visual inspection and design layout planning

---

### ✨ Key Features

* **Sidebar Navigation:** Access menu with custom iconography and playlist navigation.
* **Main Content Grid:** Responsive album cards and curated playlist layouts.
* **Bottom Player Bar:** Mock media controls, track progress bar, and volume sliders.
